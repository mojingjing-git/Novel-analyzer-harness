# 四个设计方向的最小效果验证方案

日期：2026-11-06。状态：可行性阶段的验证设计，尚未实施生产改造，也未证明质量提升。

本文件由主代理根据已曝光的真实案例整理，与 Agent 的代码可行性报告配合阅读。本轮不调用付费模型、不读取新的保留作品，不修改生产账本。

## 一、先验证什么

首轮优先验证“语义子问题 + 登记条件来源约束”。先新增旁路结果，与旧判定并列保存，不直接改变生产回收状态。

这两个方向共同回答：是不是一开始把问题问得太大，导致已有答案被全部否定；或者问题只回答了一部分，却被整体关闭？

必须区分三个状态：子问题已有回答、旧版本整条关闭条件已满足、原登记条件本身需要修订。不能把旧条件事后缩短，随后把命中数增加称为算法改善。

## 三、四种方向各自的最小验证

### A. 语义子问题

- 按问题含义拆出稳定子项，保留原父项 ID、条件版本和逻辑关系；不用句子数量代替承诺数量。
- 构造“全满足、部分满足、全部未满足、析取只满足一个分支”四类输入，观察子项和父项状态是否一致。
- 正确的部分回答应被保留，但不能因此增加不成立的整条关闭。
- 兼容检查：老账本无子项字段时能正常加载；新记录保存、恢复后父子关系和证据绑定不丢失。

### B. 增量证据历史

- 同一问题依次加入“人物猜测、确认、否定旧说法、补充条件”，验证旧证据不被覆盖。
- 同时保留原文顺序与入库顺序；补录早期章节不能被误认为故事中的最新事实。
- 重复分析同一段不重复计数；重试、重启、章节结果更新后能识别应替代的版本。
- 不允许简单采用“最后一条说法必为真”，矛盾未解决时保持分歧。

### C. 双向关联

- 新章揭晓生成候选关联，与现有“旧问题寻找后文”结果并列，不直接落成关闭判定。
- 在已曝光案例上统计新增正确关联、错误关联、重复关联及额外审核量。
- 至少覆盖别名、代称、同词不同人物、登记前已有答案四类边界。
- 关联改善与回收改善分开报告：找到相关段落不等于回答满足条件。

### D. 登记条件来源约束

- 登记阶段仅使用当前及之前的原文，记录支持问题和各项关闭要求的来源跨度。
- 将“原文明确提出、合理但待验证的推断、缺乏依据的扩展要求”分开，不把所有推断都丢弃。
- 对已经存在的老条目，旁路给出疑点，不自动改写其历史条件。
- 确需调整时建立新版本，保留修改理由及旧版评分；原有实验结果不倒填新条件。

## 四、证据与成本边界

本轮离线验证只能证明模块能衔接、状态和数据可以表达；不能证明模型会稳定拆对问题、理解指代或减少遗漏。

成本以运行记录为准，不预报百分比：

- 合并到现有章节响应中的新字段，可能不增加调用次数，但会增加输入/输出 token；二者分别统计。
- 保存证据历史与建立本地候选索引不必额外调用模型，但需测存储增长、检索耗时和提示词膨胀。
- 新关联若逐条调用模型核实，费用可能随候选增长；先限制每章候选数、去重并记录被预算延后的项。
- 双向搜索不能把每条新事件与全部旧条目逐一送模比较；先本地筛选，再对有价值的少量候选审核。
- 本轮线上调用预算为零。以后若开展模型对照，需先明确调用数、上下文长度、总 token 和允许重试次数。

## 五、进入实现阶段的判断

满足以下条件，才值得做一个默认关闭的最小生产原型：

1. Agent 找到明确复用入口及兼容方案，不需要重写分析引擎。
2. 离线契约能表达部分回答、证据归属、先后关系与登记版本，不会破坏旧记录。
3. 至少两种不同作品中的真实案例适用，且不是靠人名、关键词特判才成立。
4. 清楚列出仍需模型验证的能力与成本，不将离线状态机通过包装成效果达标。

建议交付顺序：先做 D 的登记快照与版本冻结 → A 与 D 的语义来源旁路验证 → B 的证据事件记录 → C 的有限反向关联。若代码调查发现已有等价机制，优先补接线与验证，不重复建设。

## 六、主代理复核结论

已独立复跑 `agent_probe.py`，退出码为 0，观察结果与 Agent 报告一致。它验证的是现有函数行为和数据表达缺口，并未实现或验证四种新能力的完整生产链路。

- 方向 D 中，“保存快照、计算哈希、检查条件是否改动”无需新增模型调用；“判断要求是否受到原文语义支持”仍需语义判断，不能据此承诺整个方向零新增开支。
- 工作知识列表裁剪不等于全部历史原文或存档被删除。方向 B 的核心缺口是可查询的证据演变与归属记录，而非已经证明资料永久丢失。
- 分支校验接受扩展后的条件，不代表生产调用点已经允许改题；现有调用点还有完整条件一致性检查。快照方案补的是跨阶段、跨版本的登记约束。
- 登记章节之前的证据应与后续揭晓分开；同章证据还需按原文位置判断先后，不能仅凭章节号相同就一律排除。

本轮未修改生产代码、测试、历史结果或原小说，未开展线上模型实验。模型准确率、实际成本和跨作品泛化仍待验证。
