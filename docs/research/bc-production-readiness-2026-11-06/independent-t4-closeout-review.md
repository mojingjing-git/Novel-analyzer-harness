## F1 [P1] C 答案核对仍是字词覆盖，不是独立语义裁决

位置：`scripts/bc_t4_review_c.py:59–169`。

该函数把答案分句与整个区间正文的双字片段覆盖率 ≥0.6 视为“可追溯”，进而可能判 `support`。问题与关闭条件只读入并写回报告，没有参与支持判定。它也没有核对否定、证据归属以及是否实际回答了该问题。

本次两条离线最小反例均被判为 `support`：

1. 原文“这枚令牌确实不是真品”，答案“这枚令牌确实是真品”。
2. 问题“令牌是否真品”，关闭条件“确认令牌真伪”；原文与答案均为“城主今天已经离开京城”。

四个代理的问题等价评审改善的是“是否问同一件事”，没有替代这个 C 答案质量判断。因此，不能把此函数生成的 support 直接称为独立核实的正确答案，也不能以它与管线意见不一致直接证明误杀。

处理：保留词面筛选作诊断；正式 C 标签需对具体问题、条件、回答和证据进行独立原文裁决。先核对现有名义正确项和争议项，不追加大批线上实验。

## F2 [P1] 争议样本被放入负例分母，误接受率仍用接受数作分母

位置：`scripts/bc_t4_review_c.py:282–309`、`:339–340`。

`negative_denominator` 来自“管线拒绝且 independent_verdict 为 contradict 或 dispute”的条数。争议不能视为已确认错误，且负例分母不应由管线接受/拒绝决定。`false_accept_denominator` 则仍取已接受且引文可定位的数量，并非独立负例数。

保存的 12 章报告实际为：

|臂|脚本支持|脚本确认不支持|争议|报告写的负例分母|
|---|---:|---:|---:|---:|
|baseline|1|0|42|40|
|b_fixed|5|0|36|34|
|candidate|5|0|36|34|

因此当前并没有 34 条已确认负例；按现有标签，已确认负例为零。正式负例误接受率应为 N/A，不能以 0/3、0/6 宣称该门槛通过。“尚未发现错误接受”也必须同时披露接受项中的争议数量。

处理：固定独立正例、负例、争议集合。误接受率为“被接受的已确认负例 / 全部已确认负例”；正确保留率为“被接受且正确的正例 / 全部已确认正例”。争议单列，零分母 N/A。

## F3 [P1] 一个臂的正确回答被用于给其他臂不同回答背书

位置：`scripts/bc_t4_review_c.py:354–386`。

固定集合按 `(work_id, candidate_id)` 合并：任一臂的答案被脚本标为支持，就将该 ID 加入 truth；另一个臂只要接受该 ID，即计正确保留，不再校验该臂自己的回答与证据。三臂复检分别生成回答，答案并不相同。

现有实例：`t4_urban_holdout/fs_001` 在 b_fixed 的回答被标为 support，candidate 的不同回答被标为 dispute 且被管线接受，但固定集合统计仍把 candidate 计为保留正确项。

同一问题可在某臂生成正确答案、另一臂生成不完整或过度断言的答案。“问题可以回答”与“此臂回答正确”不能混为一项标签。现有 1/7、5/7、2/7 数字不能直接作为已独立验证的正确答案保留率。

处理：如果测 C 审核，固定相同问题、条件、初次答案与证据再对照审核结果；如果测端到端回答覆盖，以独立问题参考集为共同分母，逐臂核验各自答案后计分。两种指标分开命名。

## 其他结论边界

- 每臂仅四次运行的 P95 已注明样本不足，验收状态应写“证据不足”，不能同时写“通过”。
- 目前 b_fixed 同时开启 B2、B4 和追踪，5/7 即便经校准确认，也首先是组合证据，不能单独归因于 B2。
- 成本脚本聚合的是各臂 `tokens_total` 与 `elapsed_sec`，共享分析成本另列；若称完整分析端到端成本，需明确计入共享阶段的方式。成本结论需与相同运行版本的质量结论对应。
- 已曝光扩展样本可以帮助找问题，不作为新的独立验收结果。

## 下一步只做一个有界任务

对现有 **7 个名义正确候选**逐条建立“原文—问题与条件—各臂原始回答—实际送审证据—判定与审核原因”的对照，独立复核答案及条件是否成立，并记录：

1. 真正存在可回答事实，但证据没有送到：取材问题。
2. 正确证据已送到，初次模型仍拒绝或漏答：基础复检问题。
3. 初次答案正确，升级审核错误拒绝：复审误杀。
4. 原答案不正确、仅部分回答或上下文不足：不能算误杀。
5. 判定正确但状态流转/保存出错：工程问题。

先完成这 7 条的独立核对，再决定是否优先改 baseline。无需立即扩样本，也不应仅根据当前 1/7 统计放松判定门槛。
