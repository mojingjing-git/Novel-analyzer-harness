# 实际模型对照：12个定向开发样本

模型：当前配置的 MiniMax-M3.1-Flash；temperature=0、reasoning_effort=low；每样本每版本一次，24次调用全部成功。未改生产账本。

**参考标签由本次主代理根据可见原文制定，不是人工真值。样本是已知问题定向集、不是留出测试集；不能外推全书准确率。** 一项人物解释案例预先标为待裁决，另11项作为暂定正负对照。

两组使用相同问题、候选答案与引文。处理组增加原文上下文、共享条件与新判据，是整套方案对照，不能把收益归因单一因素。部分正例答案预先收窄以忠于证据；同一收窄版本同时用于两组。

|---|---:|---:|
| 暂定负例错误接受 | 4/6 | 0/6 |

本轮新版token用量约3.65倍；以上是用量与延迟，不是货币成本。小样本零危险通过不代表总体零误报。

## 有效变化与尚未解决的问题

- fs_655：旧版因括号内的“或”放宽条件；新版沿用AND，未满足归属/来历分支即拒绝。
- fs_1000：新版识别“确认于儿神主使”不等于“排除其他幕后参与者”。
- fs_002原答案：新版认为传送已被证据回答，但鉴定/出售断言缺依据，转存疑；收窄答案fs_002_narrow被接受。说明可保留有效信息而不放过扩写。
- fs_155：新版看到梦醒上下文，未把梦中结果当确证，转存疑。
- fs_116：新版认可“认知恢复”事实，但认为“侵蚀机理”未被完整交代而拒绝。按预登记参考标签计为损失，不事后改标签。这暴露出从事实部分回答到复合问题关闭仍有边界争议。
- fs_017：两版都接受人物认知模型解释。既然预先是待裁决项，不能当确定误报或确定正确；但模型未保留来源限定的风险仍在。

## 实验后的工程调整

保留关闭判定之外的assessment_status：partial_answer（模型认可部分回答）、answer_overstated（条件可能已满足但答案扩写）、accepted与unconfirmed。使用本轮保存响应离线重放，12条接受/拒绝/存疑均未改变；未发起额外模型请求。部分结果和原始分项判断可继续审阅，不应因整条未关闭而被视为完全没有信息。

## 下一轮的明确方向

1. 把“问题已有答案”和“当前答案需要修订”分流。对fs_002类优先生成仅含受支持事实的答案，再单独核验；不需重新搜索全书。
2. 对fs_116类保留逐问题的部分状态，检查登记是否把多个目标混为一个；不要仅通过降低验收阈值找回通过率。
3. 对fs_017类增加来源明确的表述约束：结论写成“角色提出某解释”而非无主语的世界事实；需要另一份独立证据才能升级确定性。
4. 先在未用于调规则的新样本上验证，再考虑将高成本上下文核验仅用于混合条件、人物推测、梦境、跨事件等高风险项。
