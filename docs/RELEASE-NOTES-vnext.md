# vnext 交付说明（2026-10-30）

## 这一版是什么

新数据空间 `novel-analyzer-vnext`：**与旧 `workspace/` 完全隔离**，只认带 `format_id` + `schema_version` 的产物，缺标记一律拒绝（"此目录不属于本版本，请从原文创建新项目"）。不猜字段、不回退解析、不写迁移脚本。

## 能跑通什么

```
python scripts/acceptance_vnext.py -v      # 27/27
```

离线全链，零模型调用：建项目 → 块规划 → 覆盖视图 → 知识快照 → 归约 → Prompt 窗口 → 引用校验 → 伏笔视图 → 裁决 → 覆盖计数 → 任务缓存 → 预算 → 汇总。

## 与旧版最要紧的八处差别

| 旧行为 | 现在 |
|---|---|
| 正文里的数字（"第 401 章"）被判厂商错误码 → 整块永久失败 | 文本通道不可产 stop；数字码必须带 `HTTP`/`Error code` 前缀 |
| 拿"已回收"当复检缓存 | 任务账本按输入指纹记录，业务状态不再充当缓存 |
| 每块取"当前最大章号"的全量 KB → 前情随进度漂移、未来信息可泄漏 | 快照用**排他**上界，来源未知一律排除 |
| 落盘前裁剪知识库 → 历史能否留下取决于当时窗口多大 | 库永不裁剪，窗口在读取时裁剪，**截断必须报告** |
| 同章共现即关系 | 共现边与语义边分表，语义边要求显式互动证据 |
| 模型说"支持"就算回收 | 必须有可定位证据（ID + 区间 + 引文 + 校验器），否则不算 |
| 失败不扣额度 / 事后记账 | **派发前**预留，失败按实际扣，未开始可退回 |
| 任意错误都可能让全书停工 | 只有账户级永久错误跳闸，且只认结构化判定 |

## 已知限制（不要当成 bug）

1. **S9 的付费实验没跑**：A/B/C Prompt 组织方式、标注集准确率评测、接口 B 锚定风险——需要独立预算与授权。
2. **S10 打包没做**：PyInstaller 未安装，`build_exe.bat` 跑不通；Windows 安装包与首次启动向导未验证。
3. **前端没有 vnext 界面**：目前只有 `/api/vnext/*` 只读 API。1.x 界面仍读旧数据，两者并行、不跨读。
4. **名字匹配是裸子串**：`甲` 在 `甲三` 中出现也算一次，共现可能虚高；消歧属实体归并。
5. **交互保护只有规则**：持锁不 await、取消不终止工作线程——靠写法约束，没有代码守卫。

## 回滚

vnext 与旧数据零耦合：不认 vnext 目录就等于回到 1.x。危险操作只有 `workspace_vnext/` 下按项目删除。
